# Portfolio - Jai Ganesh

A modern, interactive full-stack developer portfolio built with React, TypeScript, and Framer Motion. Showcasing projects, skills, experience, and professional achievements.

## 🌟 Features

- **Smooth Animations** - Powered by Framer Motion for delightful micro-interactions
- **Responsive Design** - Mobile-first approach using Tailwind CSS
- **Dark Mode** - Modern dark theme with custom cursor
- **Type-Safe** - Built with TypeScript for robust code quality
- **Fast & Optimized** - Leveraging TanStack Start for optimal performance
- **Component Library** - Comprehensive UI components from Radix UI

## 🛠️ Tech Stack

### Frontend
- **React** - UI library
- **TypeScript** - Type safety
- **Framer Motion** - Animations and motion
- **Tailwind CSS** - Styling
- **Radix UI** - Headless UI components
- **React Router (TanStack)** - Routing
- **React Query** - Data fetching & caching

### Build & Tooling
- **Vite** - Lightning-fast build tool
- **TanStack Start** - Full-stack framework
- **ESLint** - Code quality
- **Prettier** - Code formatting

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/JaiGaneshmvp/jaiganeshmvp.git
cd jaiganeshmvp

# Install dependencies
npm install
```

### Development

```bash
# Start development server
npm run dev
```

The portfolio will be available at `http://localhost:5173`

### Building for Production

```bash
# Build the project
npm run build

# Preview the build locally
npm run preview
```

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run build:dev` - Build in development mode
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint
- `npm run format` - Format code with Prettier
